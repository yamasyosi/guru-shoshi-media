# グルメ司法書士のレストランナビ

「司法書士なのに、なぜか本気で食レポする」——グルメ司法書士による食レポ・Webメディアです。
ビルド不要の静的サイト（HTML / CSS / Vanilla JS）として構成されており、Vercel にそのままデプロイできます。

## サイト構成

```
.
├── index.html          # トップページ（コンセプト＋食レポ一覧＋エリア絞り込み）
├── article.html        # 食レポ詳細ページ（?slug= で記事を出し分け）
├── profile.html         # グルメ司法書士のプロフィールページ
├── css/style.css        # 全ページ共通スタイル
├── js/
│   ├── main.js           # 共通ユーティリティ（データ読み込み・日付整形など）
│   ├── home.js           # トップページのカード一覧描画＋エリア絞り込みUI
│   └── article.js        # 記事詳細ページの描画
├── data/
│   └── reports.json      # ★食レポ記事データ（ここを編集して記事を追加）
├── sitemap.xml           # SEO用サイトマップ（記事追加のたびに更新）
├── robots.txt            # クローラー向け設定
└── vercel.json           # Vercel用の設定（クリーンURLなど）
```

## 新しい食レポを追加する方法

コードは一切触らず、`data/reports.json` に1件オブジェクトを追記するだけで
トップページの一覧・詳細ページの両方に自動で反映されます。

```json
{
  "slug": "shop-unique-id",              // URL用の一意なID（半角英数とハイフン）
  "title": "記事タイトル",
  "shopName": "お店の名前",
  "area": "エリア表記（例：東京都・神保町）",
  "prefecture": "東京都",                // ★エリア絞り込みタグ：都道府県
  "ward": "千代田区",                    // ★エリア絞り込みタグ：区市町村
  "visitDate": "2026-09-01",             // 訪問日（YYYY-MM-DD）
  "photo": "https://example.com/photo.jpg", // 店舗写真URL（ダミーでも可）
  "excerpt": "一覧カードに表示される短い紹介文",
  "review": [
    "本文の段落1",
    "本文の段落2",
    "本文の段落3"
  ],
  "mapQuery": "検索用の住所やお店の名前",   // Googleマップ埋め込み用（簡易指定）
  "officialUrl": "https://example.com"     // 公式サイト・予約ページのURL
}
```

- `mapQuery` の代わりに、Googleマップの「地図を埋め込む」機能で発行した iframe の
  `src` URLをそのまま `mapEmbedUrl` として指定することも可能です（APIキー不要）。
- 記事は `visitDate` の新しい順に自動で並び替えて表示されます。
- 削除したい記事は、該当オブジェクトを配列から削除するだけでOKです。
- `photos` 配列（`{ "url": "...", "caption": "..." }` の形）を追加すると、詳細ページに複数写真のギャラリーが表示されます（省略時は `photo` の単一写真のみ表示）。

### エリア絞り込みタグ（`prefecture` / `ward`）について

トップページの「📍 エリアで絞り込む」は、`reports.json` 内の `prefecture`（都道府県）と
`ward`（区市町村）を自動集計して選択肢と件数を生成しています。つまり：

- **必ず**新しい記事に `prefecture` と `ward` を含めてください（フィルターから漏れてしまいます）。
- 新しい都道府県（例：神奈川県、埼玉県）の記事を追加すると、選択肢に自動的に追加の都道府県ピルが出現します。コード側の修正は一切不要です。
- `ward` は「新宿区」「さいたま市」のように、都道府県の1段下の行政区分を入れてください。

### 記事追加時のチェックリスト

1. `data/reports.json` に記事オブジェクトを追記（`prefecture` / `ward` を忘れずに）
2. 写真を `images/` に配置（サイズが大きい場合はリサイズ・圧縮を推奨）
3. `sitemap.xml` に記事URLを追記（`<loc>` は `article.html?slug=...` 形式）
4. GitHubにpush → Vercelが自動デプロイ

## ローカルでの確認方法

このサイトは静的ファイルのみで動作しますが、`fetch()` でJSONを読み込む都合上、
`file://` で直接開くと動作しません。簡易サーバー経由で確認してください。

```bash
node _devserver.js
# または
npx serve .
# または
vercel dev
```

> `_devserver.js` はローカル確認専用の軽量サーバーです。Vercel本番環境には影響しません。

## デプロイ

GitHubリポジトリにpushすると、VercelのGit連携により自動的にビルド・公開されます
（静的サイトのためビルドコマンドは不要です）。
